* *ScrollFlow for YouTube Extension*



*A lightweight Chrome extension that improves the YouTube watching experience with smarter scrolling behavior and a sticky video player.*



* *Features*



*\* Sticky video player while scrolling*

*\* Cleaner viewing layout*

*\* Minimal and distraction-free experience*

*\* Lightweight and fast*



* *Goal*



*This project explores better UX possibilities for the YouTube watch page, especially improving multitasking while browsing recommendations and comments.*



* *Tech Stack*



*\* JavaScript*

*\* CSS*

*\* Chrome Extension Manifest v3*
